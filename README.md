# english-teacher-audio

Audio for the [english-teacher](https://github.com/neryabenami/english-teacher) app, made with the open-source
[Kokoro](https://huggingface.co/hexgrad/Kokoro-82M) voice "Heart" (Apache-2.0). Served by GitHub Pages.

- `w/` words, slang, useful expressions and their example sentences (kept for good)
- `a/<article>/` the sentences of the articles of the last 30 days
- `index.json` what has audio
